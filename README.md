# Jheremie Santos: portfolio

`index.html` is the main portfolio page. Every project opens from it.

```
index.html              portfolio (main page)
assets/                 portfolio-only files
  css/main.css  js/main.js  js/interactions.js
  images/               portrait + StayEasy cover
  resume/               Jheremie_Santos_Resume.pdf
projects/
  stockpilot/        index.html (shop) + admin.html
  crumb-and-co/      index.html (shop) + owner-admin.html
  skycast/
  counter-pos/
  ashden-manor/
  marci-metzger/
  stayeasy/
    each project:  index.html  css/  js/  images/
archive/unused/         web.css, web.js (old template files nothing linked to)
```

In projects 01-04, `css/motion.css` and `js/motion.js` hold the animation layer.
Delete those two links in the project's HTML to switch the extra animation off.
